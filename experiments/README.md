# Stress Test: Baseline vs Control V4

This folder contains scripts to reproduce a Figure-12-style stress comparison between:
- a trained baseline diffusion model, and
- a Control V4 model (base diffusion backbone + trained control weights).

## What You Need

1. Input condition image:
- Either generated stress map (synthetic), or
- An existing image (for example, a plant image).

2. GBN stippling dataset assets:
- Generate stipplings using Gaussian Blue Noise (GBN) tooling.
- Reference repo: https://github.com/OfirGiladBGU/GaussianBlueNoise

3. Trained baseline model files (from this repo root train flow):
- Baseline JSON config (for sampling/parsing), and
- Baseline checkpoint with `diffu` weights.

4. Trained Control V4 model files:
- Control branch JSON config,
- Control branch base diffusion checkpoint with `diffu` weights,
- ControlNet trained weights checkpoint (`--control-ckpt`).

Important: baseline and control paths can now be fully different.

Expected path layout for this repo:
- Baseline (separate trained baseline model):
  - `GBN/config.json`
  - `GBN/model.ckpt`
- Control branch:
  - `config/GBN/config.json`
  - `config/GBN/model.ckpt` (or `config/GBN/model.ckp`)
  - `control_v4/train_outputs/checkpoints/<best_controlnet...>.pt`

## Workflow

1. Generate stress map (optional if using a real image):

```bash
python experiments/generate_stress_map.py
```

This saves:
- `experiments/stress_test_density.png`

2. Prepare stippling data with GBN:
- Use the GBN repo to build the target stippling dataset for your selected images.

3. Train baseline model:
- Run this repo's root training flow (`train.py`) on that dataset.
- Save resulting baseline config and checkpoint paths.

4. Train Control V4 model:
- Train Control V4 on the same dataset.
- Save control config, control base checkpoint, and control-net checkpoint.

5. Run side-by-side stress comparison:

```bash
python experiments/run_stress_test.py \
  --compare-image experiments/stress_test_density.png \
  --baseline-config GBN/config.json \
  --baseline-ckpt GBN/model.ckpt \
  --control-base-config config/GBN/config.json \
  --control-base-ckpt config/GBN/model.ckpt \
  --control-ckpt <PATH_TO_CONTROLNET_WEIGHTS>
```

You can also run on a real image by replacing `--image` with your image path.

## Key CLI Arguments

Required model file paths (5 total):
- Baseline (2):
  - `--baseline-config`
  - `--baseline-ckpt`
- Control (3):
  - `--control-base-config`
  - `--control-base-ckpt`
  - `--control-ckpt` (alias: `--controlnet-ckpt`)

Other required input:
- `--compare-image` (alias: `--image`)

Model path controls:
- `--baseline-config`
- `--baseline-ckpt`
- `--control-base-config`
- `--control-base-ckpt`

Checkpoint extension note:
- The script accepts `.ckpt` or `.ckp` for baseline/control base diffusion checkpoints.
- If one extension is provided but the file does not exist, it will automatically try the alternate extension.

Useful optional knobs:
- `--sample-timesteps`
- `--truncation-ratio`
- `--resample-jumps`
- `--smart-init-seed`
- `--grid-size`
- `--n-samples` (number of outputs generated by each model)
- `--panel-sample-index` (which sample index to render in comparison panel)
- `--use-sdf` / `--no-use-sdf`
- `--enable-gecco` / `--no-enable-gecco`

## Outputs

By default results are saved under:
- `experiments/outputs/<image_stem>/`

Artifacts include:
- `comparison_panel.png` (Condition, Smart Init, Baseline, Control V4)
- `baseline_offsets.npy`, `control_v4_offsets.npy`, `smart_init_offsets.npy`
- `baseline_points.npy`, `control_v4_points.npy`, `smart_init_points.npy`
- Printed spacing metrics (CV, clumped %, spacing score)

Multi-sample behavior:
- `baseline_offsets.npy` and `control_v4_offsets.npy` store all generated samples with leading sample dimension.
- `baseline_points.npy` and `control_v4_points.npy` store all generated point sets with leading sample dimension.
- Printed metrics include one line per sample for baseline and control.

## Notes

- The compare script uses a shared noisy start (`x_noisy`) for both branches.
- This keeps baseline vs control comparison fair at inference time.
- If you add future predict scripts, consider extracting shared model-loading and condition-building helpers from `run_stress_test.py` into a common module to avoid duplication.
